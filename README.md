# my-app-trans — 한국어 → 다국어 번역 입력기

윈도우 트레이에 상주하다가, 전역 단축키를 누르면 마우스 커서 근처에 입력창이 뜨고,
거기에 글을 입력하면 OpenRouter LLM이 설정한 목표 언어로 번역해 **원래 커서가 있던
입력란에 자동으로 붙여넣어** 줍니다. (중국어 병음 입력처럼, 한국어로 쓰면 선택한
언어로 들어가는 경험)

- 번역 엔진: OpenRouter (기본 모델 `google/gemini-2.5-flash-lite`)
- 목표 언어: 영어 / 중국어 / 베트남어 / 한국어
- 기본 단축키: `Ctrl+Shift+Z`
- 붙여넣기까지만 하고 **전송은 사용자가 직접** (안전)

## 설치

```powershell
pip install -r requirements.txt
```

(Python 3.14 기준. tkinter는 파이썬에 내장되어 있습니다.)

## 설정

설정 파일 위치:

```
%APPDATA%\my-app-trans\config.json
```

```json
{
  "openrouter_api_key": "sk-or-v1-...",
  "model": "google/gemini-2.5-flash-lite",
  "target_language": "영어",
  "hotkey": "ctrl+shift+z"
}
```

API 키는 이 파일에 직접 넣거나, 실행 후 **트레이 아이콘 > 설정 열기**에서 입력할 수
있습니다. 키는 이 파일(APPDATA)에만 저장되며 코드/깃에는 들어가지 않습니다.

## 실행

```powershell
python main.py
```

- 트레이에 아이콘이 생깁니다. 우클릭 → **설정 열기 / 종료**.
- 콘솔 창 없이 띄우려면 `pythonw main.py` 를 쓰거나 바로가기를 만드세요.

## 사용법

1. 글을 넣고 싶은 곳(메모장, 브라우저, 메신저 등)에 커서를 둡니다.
2. `Ctrl+Shift+Z` 를 누릅니다 → 마우스 근처에 입력창이 뜹니다.
3. 한국어로 입력하고 **Enter** → 번역되어 원래 입력란에 붙여넣어집니다.
4. (채팅이라면) 직접 **Enter** 를 한 번 더 눌러 전송합니다.
5. 취소는 **Esc**.

## 자동 감지 모드 (실험적)

설정창의 **"자동 열기"**(입력란을 클릭하면 열기)를 체크하면, 단축키를 누르지 않아도 **텍스트 입력란을
클릭(포커스)할 때마다 팝업이 자동으로 뜹니다.** (Windows UI Automation 사용)

- 같은 입력란에서는 한 번만 뜨고, 다른 입력란으로 옮기면 다시 뜹니다.
- Esc로 닫으면 그 입력란에서는 다시 안 뜹니다(다른 곳 갔다 오면 재동작).
- **마우스로 다시 클릭하면** 같은 입력란이라도 팝업이 다시 뜹니다. (팝업이 떠
  있는 동안의 클릭이나 붙여넣기 직후 자동 포커스 복귀는 재팝업을 일으키지 않습니다.)
**입력란 판정 방식:** 컨트롤 종류가 아니라 **편집 가능 여부(UIA ValuePattern, 읽기
전용 아님)**로 판정합니다. 덕분에:
- 검색창·주소창·대부분의 입력창처럼 "커서가 생기는 곳"에서 동작
- 읽기 전용 웹페이지(브라우저 탭/아이콘 클릭 시 포커스되는 곳)·버튼·탭에서는 안 뜸

접근성 정보를 노출하지 않는 앱(WeChat 등)은 **시스템 텍스트 커서 감지(캐럿 폴백)**로
보조 인식합니다 — 입력칸을 클릭해 커서가 깜빡이면 자동으로 뜹니다. 단, 자체적으로
커서를 그리는 일부 Electron 앱(예: Claude 데스크탑)은 시스템 커서가 없어 자동 감지가
안 될 수 있고, 그땐 단축키(`Ctrl+Shift+Z`)를 쓰면 됩니다.

어떤 앱이 어떻게 인식되는지는 진단으로 확인하세요:

```powershell
python diag_autodetect.py
```
대상 앱의 입력란을 클릭했을 때 `감지=True` 로 찍히면 자동 팝업이 동작합니다.
**안 뜨는 앱이나 잘못 뜨는 곳이 있으면, 그 출력 한 줄을 알려주시면 판정 기준을
맞출 수 있습니다.** (메모장·터미널·Gmail 작성창 동작 확인됨)

## 문제 해결 / 진단

- **단축키가 안 먹힐 때:** `python diag_hotkey.py` 실행 후 `Ctrl+Shift+Z`를 눌러
  `HOTKEY DETECTED`가 찍히는지 확인. 안 찍히면 PowerShell을 **관리자 권한**으로
  실행하세요.
- **자세한 로그로 실행:** `python main.py --debug` — 단축키 감지(L1)부터 팝업
  생성(L4), 자동 감지(AUTO)까지 콘솔에 단계별로 출력됩니다.

붙여넣기(주입) 동작은 실제 데스크톱에서만 확인됩니다. 아래 자체 테스트를 실행하고,


## 알려진 제약

- **관리자 권한 앱**(작업 관리자 등)에는 붙여넣기가 안 될 수 있습니다(권한 문제).
  필요하면 이 프로그램도 관리자 권한으로 실행하세요.
- 일부 단축키는 다른 프로그램과 충돌할 수 있습니다. 그럴 땐 설정에서 단축키를
  바꾸세요.
- 텍스트 캐럿 "바로 위"가 아니라 마우스 커서 근처에 입력창이 뜹니다(설계상 선택).

## 구조

| 파일 | 역할 |
|------|------|
| `main.py` | 트레이 + 단축키 + 스레드 조율 (진입점) |
| `config.py` | 설정 로드/저장 (`%APPDATA%`) |
| `translator.py` | OpenRouter 번역 호출 |
| `inject.py` | 포커스 복귀 + 클립보드 백업/복원 + Ctrl+V 주입 |
| `popup.py` | 마우스 근처 입력 팝업 |
| `settings_window.py` | 설정 GUI |
